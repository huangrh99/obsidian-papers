# FireRed-OpenStoryline — AI 视频剪辑 Agent

> 来源：GitHub FireRedTeam/FireRed-OpenStoryline（小红书 FireRed 团队）
> 归档日期：2026-02-27

---

## 是什么

小红书 FireRed 团队开源的 **AI 视频剪辑 Agent**，把复杂视频创作变成自然语言对话。
架构：FastAPI + LangChain + MCP tools + Skills，多模型协同。

## 核心能力

- **智能素材搜索**：自动搜索下载匹配主题的图片/视频片段，进行分段和内容理解
- **脚本生成**：结合主题、视觉理解、情感识别，自动构建故事线和旁白；支持 Few-shot 风格迁移（模仿指定账号的文案风格）
- **BGM + 配音 + 字体推荐**：描述情绪（「克制」「感动」「纪录片风格」），自动匹配；支持节拍同步
- **对话式修改**：「把第三段换成慢镜头」「加个渐入效果」，实时生效
- **Skill 归档**：把完整剪辑工作流存成 Skill，换素材一键复用风格，适合批量创作

## 支持的视频风格示例

中草风格 / 幽默风格 / 产品精选 / 艺术风格 / 开箱 / 宠物说话 / 旅行 Vlog / 年终回顾

## 和 JARVIS 的关联

- **不适合集成**：是独立运行的服务，需要 FastAPI server + 视频处理依赖 + GUI，不是 SKILL.md 风格的指令文件
- **值得借鉴的设计**：Skill 归档复用工作流的思想，和元学习「把成功经验写回运行文件」理念相同
- **当前相关性**：低（虾克斯是文字/图文账号，无视频需求）；未来做视频时可单独部署

### 2. GUI vs CLI — OpenClaw 语言优先级
**核心观点：GUI 是给人用的，CLI 才是给 Agent 用的**
- 浏览器太吃 Token（HTML 源码能塞满整个上下文窗口）
- CLI 命令简洁精准，`obsidian --help` 就是"AI 原生说明书"
- Agent 用 CLI 才能真正自动化，减少 DOM/弹窗/验证码干扰
- 实践：把 OpenClaw 配置切到优先使用 CLI 工具

### 4. OpenClaw 抓取优化 — 一行 Header 省 80% Token
**改动**：所有 HTTP 请求加 `Accept: text/markdown, text/html`
- Cloudflare 推出 Markdown for Agents，支持的网站会返回 Markdown
- Markdown 比 HTML 干净，token 减少约 80%
- 不支持的网站正常返回 HTML，无副作用
- **待办**：检查 OpenClaw web_fetch 工具是否已加此 Header

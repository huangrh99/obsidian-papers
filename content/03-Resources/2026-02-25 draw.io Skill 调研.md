# draw.io 官方 Skill 调研（2026-02-25）

## 来源
https://github.com/jgraph/drawio-mcp/tree/main/skill-cli

## 方案选择

| 方案 | 说明 | 需要 |
|------|------|------|
| skill-cli | 生成原生 .drawio 文件，可导出 PNG/SVG/PDF | draw.io 桌面 App |
| mcp-tool-server | 打开浏览器 draw.io 编辑器 | npm @drawio/mcp |
| mcp-app-server | 在聊天中内嵌渲染 | 托管服务或自部署 |

**推荐：skill-cli**，无需 MCP，生成文件带内嵌 XML 永久可编辑。

## 安装状态
- Skill 文件：已下载到 `~/.agents/skills/drawio/SKILL.md` ✅
- draw.io App：**未安装**，需要手动安装

## 安装 draw.io App
https://github.com/jgraph/drawio-desktop/releases
或 https://www.drawio.com

## CLI 导出命令
```bash
/Applications/draw.io.app/Contents/MacOS/draw.io -x -f png -e -b 10 -o output.drawio.png input.drawio
```

## 核心优势
- 内嵌 XML（PNG/SVG/PDF 都可以在 draw.io 重新编辑）
- 无需 MCP Server
- 官方出品，长期维护

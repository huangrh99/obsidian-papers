# Qwen-Image

## 📌 核心贡献

> BINet提出了一种新颖的二值修复网络，旨在解决深度块级图像压缩中相邻图像块间依赖性缺失导致的低码率块状伪影问题。它通过在自编码器框架中整合二值修复技术，有效地重建了图像块间的相互依赖关系，显著提升了块级压缩的图像质量。

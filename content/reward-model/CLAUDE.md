# Reward Model 研究目录

## 项目背景

正在系统性调研 reward model 领域，目标是设计一个支持 **image + video** 的统一 reward model。GPU 资源：8×H100。

## 当前状态

- **62 篇论文笔记**，覆盖 Text / Image / Video / Multimodal RM、评估基准、Survey
- `RM-Survey.md`：综合调研报告（方法分类 + 性能对比 + 趋势分析 + 统一 RM 设计方案）

## 维护规则

**添加新论文时，必须同步更新 `RM-Survey.md`：**

1. 在「方法分类总表」中添加新行
2. 在「双轴分类体系」网格中填入对应位置
3. 如有性能数据，更新「性能横评」相关表格
4. 如涉及新范式/趋势，更新「演进时间线」和「Gap 分析」
5. 在「参考文献索引」中添加 `[[]]` 链接

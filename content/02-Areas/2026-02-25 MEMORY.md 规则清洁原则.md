# MEMORY.md 规则清洁原则

## 核心内容

明确了什么内容应该放进 MEMORY.md（全局规则层），什么不应该。

## 原则

**放入 MEMORY.md 的内容**：
- 真正影响全局决策的禁止项和行为约束
- 触发词（影响所有会话的 routing 规则）
- 关键事实（Boss 基本信息、频道 ID 等）

**不应放入 MEMORY.md 的内容**：
- 特定 skill 的操作步骤（由 SKILL.md 自己管）
- 工具配置细节（放 L1 的 memory/tools.md）
- 项目状态细节（放 L1 的 memory/projects.md）

## 最终规则区（只剩两条）

```markdown
## 规则（必须遵守）
- 禁止 Playwright → 统一 browser tool（profile=openclaw 首选）
- 禁止 fast-response-1 beta
```

## 触发词规则

```markdown
## 触发词
- `xhs:` → 读 xhs-publisher SKILL.md + PERSONA.md
- `记录:` / `kb:` / `帮我归档` → 知识库归档
```

（ArXiv URL 不再自动触发任何流程）

## 为什么重要

防止 MEMORY.md 成为"什么都往里塞"的垃圾桶，保持 L0 层的精简和全局适用性。skill 内部的废弃脚本（如 publish.py）不是全局规则，不应出现在 MEMORY.md。

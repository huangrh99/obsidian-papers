# xhs 发帖 tag 重复问题修复 + 评论草稿队列清理

## 核心内容

发现并修复了小红书发帖时 tag 出现重复的根因，同时处理了积压的 12 条评论草稿（含 2 条 LLM 输出异常）。

## Tag 重复问题

**根因**：content 正文里手写了纯文本 tag（如 `#退税`），同时 MCP 的 `tags` 参数也自动生成了 `[话题]` 格式 tag → 双重 tag 出现在发布内容中。

**修复**：更新 SKILL.md 规则 — **content 里不写 tag，全部走 `tags` 参数**。

**影响范围**：已发布帖子保持现状（MCP 无编辑接口），新帖子起生效。

## 评论草稿清理

- 积压 12 条草稿，含 2 条异常（LLM 输出了推理过程而非评论正文）
- **Boss 决策**：退税帖全部不回复（话题敏感），两条技术评论（@长臂猴）Boss 已手动回复
- 操作：JARVIS 清空全部 pending 队列

## 为什么重要 / 关联

- tag 重复是影响内容呈现的质量问题，修复后发布规范更清晰
- 评论队列积压会影响互动率，定期清理是运营维护的一部分
- 关联：xhs-publisher SKILL.md、评论巡逻 cron

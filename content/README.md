# 知识库

由 JARVIS (OpenClaw) 自动维护的个人知识库，基于 PARA 方法论。

## 目录结构

| 文件夹 | 含义 | 存放内容 |
|--------|------|----------|
| `00-Inbox` | 收件箱 | 所有新输入，待分类 |
| `01-Projects` | 项目 | 有明确目标和截止日期的事项 |
| `02-Areas` | 领域 | 长期持续关注的领域（健康、财务、技术等） |
| `03-Resources` | 资源 | 参考资料、好文章、工具、教程 |
| `04-Archives` | 归档 | 已完成或暂时不活跃的内容 |

## 如何使用

通过 iMessage 发给 JARVIS：

- `记录: [任何内容]` — 自动分析并归档
- `记录: [URL]` — 抓取文章内容，摘要后归档
- `记录: 想法 [内容]` — 直接进 Areas 或 Inbox
- `记录: 项目 [内容]` — 进 Projects

JARVIS 会自动判断分类，写成结构化笔记。

## 维护规则

- 每周自动生成周报（位于 `02-Areas/每周回顾/`）
- Inbox 积累超过 20 条时 JARVIS 会提醒整理

# xhs-mcp 迁移完成

## 核心内容

2026-02-23，Boss 下令禁止所有旧的小红书操作方式，全面迁移到 xhs-mcp（基于 REST API 的 MCP Server）。

## 新方案架构

| 组件 | 路径 | 说明 |
|------|------|------|
| MCP Server | `~/bin/xiaohongshu-mcp` | 常驻后台，内置 Chromium+rod |
| REST API | `http://localhost:18060/api/v1` | 所有操作入口 |
| 客户端脚本 | `~/.agents/skills/xhs-mcp/xhs.py` | 封装命令行工具 |
| 技能文件 | `~/.agents/skills/xhs-mcp/SKILL.md` | 操作规范 |

## 禁用的旧方案

- ❌ `MediaCrawler`（`run_search.sh` / `run_detail.sh`）
- ❌ `publish.py` / `xhs_poster.py` / `login.py`
- ❌ Playwright（Boss 2026-02-22 明令禁止）

## 新方案常用命令

```bash
# 搜索
python ~/.agents/skills/xhs-mcp/xhs.py search "关键词"

# 发布图文
python ~/.agents/skills/xhs-mcp/xhs.py publish "标题" "正文" img.jpg

# 检查登录状态
python ~/.agents/skills/xhs-mcp/xhs.py status
```
